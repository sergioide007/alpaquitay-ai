# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Email **[sergio@specsolid.com](mailto:sergio@specsolid.com)** (alternative: [sergioide007@gmail.com](mailto:sergioide007@gmail.com)) with:

- the Alpaquitay AI version and your VS Code version and OS;
- what an attacker can do, and the steps to reproduce it;
- a proof of concept, if you have one.

You will get an acknowledgement within **5 business days**. Once the issue is confirmed, a fix is released as soon as
possible and you are credited in the [CHANGELOG](CHANGELOG.md), unless you prefer to stay anonymous.

## Supported versions

Only the latest release published on the VS Code Marketplace receives security fixes.

## Scope

In scope: the extension source in this repository ([github.com/sergioide007/alpaquitay-ai](https://github.com/sergioide007/alpaquitay-ai)).
Out of scope: vulnerabilities in third-party AI providers or in VS Code itself; report those to their vendors.
