Workspace Root Invariant

Código Sintético Cap. 09 — invariants are encoded, not suggested. The harness never writes through a path it did not first validate.

WorkspaceRoot.ts resolves the root by priority (workspaceFolders → workspaceFile dir → cwd) and rejects: empty, relative, undefined, and filesystem roots (/, C:\, \\share). Empty workspaceFolders used to fall back to process.cwd(), which in the extension host is often / — a read-only mount: 

Error: EROFS: read-only file system, open 'spec.md'

Guarantees

  • SpecManager.specPath returns '' when no writable root exists; all spec writes funnel through one guarded _write().
  • FilesystemMCP validates the root before resolving a path and translates EROFS / EACCES / ENOENT / EISDIR into actionable messages.
  • Every mutation path runs a preflight (chat Build, regenerate-spec, si aplicar, delete, arch/ADR/infra export, specs/* template, checkpoints, Git MCP).
  • With no writable root the harness degrades to chat mode — it explains the fix instead of failing silently.
  • Path containment uses path.relative(), not startsWith(), so /tmp/app2 cannot masquerade as /tmp/app.

Privacy Boundary

Alpaquitay AI is privacy-first by design. Your code and prompts travel only to the provider you configure.

What we never do

  • No telemetry is collected by default. Opt-in only.
  • No Alpaquitay server sits between you and your AI provider — direct connection always.
  • API keys are stored in the OS keychain, never in settings.json or logs.
  • PII and secrets are redacted by PrivacyBoundaryProvider before any prompt leaves the machine.
  • Local provider (Qwen 2.5 Coder) runs fully on-device: no network, no key, no cost.
🔗

MCP Servers

The harness exposes two built-in Model Context Protocol servers, registered via MCPManager.

FilesystemMCP
Sandboxed read/write inside the validated workspace root. Translates OS errors into actionable messages. Rejects paths outside the root.
GitMCP
Git log queries for DORA metrics, standup summaries, and checkpoint creation. Read-only except for checkpoint commits.
